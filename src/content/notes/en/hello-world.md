Welcome to my new website! This note is also an example of how to write your own.

## Math

You can write formulas inline, like $\sqrt{2} \notin \mathbb{Q}$, or as a block:

$$
\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}
$$

## How to write a new note

1. Create a `.md` file in `src/content/notes/en/` (or `es/` for Spanish).
2. Copy the block at the top between the `---` lines and change the title and date.
3. Write! The note shows up on the notes page by itself.

> If you write the same note in both languages, give them the same `translationKey` and the language button will link them.
